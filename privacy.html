Политика конфиденциальности DeniZ

DeniZ — личное приложение, которым пользуется только его владелец, Денис Зиновьев, со своими аккаунтами Google.

  • Приложение получает доступ к данным Google (почта, календарь, задачи, контакты, документы, диск) только тех аккаунтов, владелец которых сам дал разрешение.
  • Данные используются только для помощи владельцу: чтение и поиск писем, подготовка черновиков, работа с календарём и задачами.
  • Данные не продаются, не передаются третьим лицам и не используются для рекламы.
  • Токены доступа хранятся локально на компьютере владельца. Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

DeniZ is a personal app used only by its owner, Denis Zinoviev, with his own Google accounts. It accesses Google user data (Gmail, Calendar, Tasks, Contacts, Docs, Drive) only for accounts whose owner granted permission, uses it solely to assist the owner, never sells or shares it with third parties, and stores tokens locally. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
